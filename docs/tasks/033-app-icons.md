# 033 · App icons for the packaged app (icon.ico, icon.icns)

## Objective
The packaged launcher, Start-menu shortcut and macOS bundle show a snapsolve icon instead of Electron's default.

## Scope
In:  `assets/icon.ico` (16–256 px) and `assets/icon.icns`, generated by a script in `scripts/` from one source image; the release (022) already copies `assets/`, and 023/031 pass the icon to packager when present.
Out: tray icons (010).

## Done when
- [ ] both files exist and a test checks their headers (`.ico` reserved/type bytes `00 00 01 00`, `.icns` magic `icns`) and that the .ico holds a 256 px image

## Tests
Command: to be set when the task is pulled into a milestone.
- `.ico` header and a 256 px entry; `.icns` magic and length field matching the file size.

DESIGN §4 (plugin tree: `assets/icon.ico`, `assets/icon.icns`), §4.2 step 3 (packager `icons`).
