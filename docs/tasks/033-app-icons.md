# 033 · App icon for the packaged macOS app (icon.icns)

## Objective
The packaged macOS bundle (`~/Applications/snapsolve.app`) shows a snapsolve icon instead of Electron's default. (Windows `.ico` archived with Amendment 4.)

## Scope
In:  `assets/icon.icns`, generated by a script in `scripts/` from one source image; the release (022) already copies `assets/`, and 031 passes the icon to packager when present.
Out: tray icons (010).

## Done when
- [ ] `assets/icon.icns` exists and a test checks its `icns` magic and that it holds a 512 px (or larger) image

## Tests
Command: to be set when the task is pulled into a milestone.
- `.ico` header and a 256 px entry; `.icns` magic and length field matching the file size.

DESIGN §4 (plugin tree: `assets/icon.ico`, `assets/icon.icns`), §4.2 step 3 (packager `icons`).
